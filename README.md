# 🎓 Anonymous Student Discussion Telegram Bot
> **نظام إدارة الأسئلة والمناقشات الطلابية المجهولة عبر قنوات تيليجرام الخاصة (Production-Grade & Zero-Trust Architecture)**

---

## 🌟 نظرة عامة (Overview)

تم بناء هذا البوت هندسياً لتمكين الطلاب في القنوات التعليمية الخاصة من طرح الأسئلة، الاستفسارات، والمشاركة بالوسائط والمستندات بأسماء وهوية مجهولة ومستقرة تماماً (`طالب #101`)، مع ضمان الحماية القصوى لخصوصية الطلاب وفق مبادئ **Zero-Trust** وتشفير البيانات في حالة السكون **Encryption-at-Rest**، وفصل الصلاحيات الصارم بين المالك والمشرفين **RBAC**، والتطهير الجنائي للوسائط **EXIF/GPS Sanitization**، وحماية المحتوى من التحويل والنسخ `protect_content=True`.

---

## 🛡️ ركائز الأمان والخصوصية (Security Architecture)

### 1. نظام الهوية المجهولة الآمن (Anonymous Identity System)
* **معرف مجهول ثابت وغير قابل للاشتقاق:** تخصيص أرقام تسلسلية متتابعة تبدأ من `101` باستخدام متسلسلة PostgreSQL ذرية (`anonymous_student_id_seq`)، مما يقضي تماماً على ثغرات الـ Race Conditions والتصادمات أثناء الضغط المتزامن.
* **خزنة الهوية المعزولة (Identity Vault):** تخزين جميع البيانات الشخصية (`telegram_id`, `full_name`, `username`) مشفرة عسكرياً عبر خوارزمية **Fernet (AES-128-CBC + HMAC-SHA256)** مع فهارس عمياء مشتقة عبر مفتاح منفصل باستخدام **HKDF HMAC-SHA256 Blind Index** للبحث السريع دون كشف البيانات.
* **منع تجاوز الحظر (Permanent Ban Tracking):** تسجيل بصمات المعرفات المشفرة للمحظورين في جدول `banned_fingerprints` لضمان عدم قدرتهم على التحايل وتجاوز الحظر عبر أمر مسح البيانات `/forget_me`.
* **حظر وصول المشرفين:** لا يمكن لأي مشرف (Moderator) أو طالب أو واجهة برمجية أو سجل تسجيل (Logs) الاطلاع على هويات الطلاب، وحصر فك التشفير حصرياً في المسؤول الأساسي الموثق (`PRIMARY_ADMIN`).

### 2. التحكم في الوصول المستند إلى الأدوار (Strict RBAC)
* **المسؤول الأساسي (Primary Admin):**
  * كشف الهوية المشفرة (`/whois`).
  * تعيين وإدارة كلمات المرور الفردية للمشرفين (`/set_admin_password`).
  * تطهير ومحو بيانات الطالب نهائياً وفق معايير الخصوصية و GDPR (`/wipe_student`).
  * الإذاعة العامة لجميع الطلاب (`/broadcast`).
  * إرسال رسائل خاصة رسمية مجهولة للطالب (`/dm`).
  * إدارة وضبط إعدادات القناة والتحكم في النشر.
* **المشرفون (Moderators):**
  * حظر وإلغاء حظر الطلاب (`/ban`, `/unban`).
  * كتم وإلغاء كتم الطلاب مؤقتاً (`/mute`, `/unmute`).
  * حذف المنشورات والردود المسيئة من القناة (`/del`).
  * مراقبة سجلات الرقابة (الخالية تماماً من الـ PII).
  * **محظور عليهم تماماً:** استخدام `/whois`, `/dm`, `/wipe_student`, `/broadcast`, `/set_admin_password` أو فك تشفير أي هوية.

### 3. مصادقة المشرفين الآمنة (Scrypt 2FA & Session Lockout)
* حماية لوحة التحكم والأوامر الرقابية بكلمة مرور مشفرة بتجزئة **Scrypt** مع Salt عشوائي فريد (بدون أي نصوص صريحة).
* دعم كلمات مرور فردية لكل مشرف عبر جدول `admin_credentials` في PostgreSQL، مع تراجع آمن إلى متغير البيئة `ADMIN_PASSWORD_HASH`.
* إدارة الجلسات واستمراريتها في قاعدة البيانات مع صلاحية زمنية محددة (`ADMIN_SESSION_EXPIRY_MINUTES`).
* درع الحماية ضد التخمين (Brute-Force Protection): إقفال الحساب تلقائياً لمدة 15 دقيقة بعد 5 محاولات خاطئة (مع حفظ المحاولات في PostgreSQL).
* حذف رسائل كلمة المرور فور كتابتها في المحادثة لمنع استراق النظر.

### 4. معالجة وتطهير الوسائط والملفات (Media Sanitization Pipeline)
* **تنزيل معزول:** تنزيل الوسائط في مجلد محلي مؤقت (`media_tmp/`).
* **تطهير البيانات الوصفية:** فتح الصور عبر مكتبة **Pillow** وإعادة رسمها على لوحة نظيفة وتجريدها بالكامل من وسوم **EXIF / GPS / Device Metadata**.
* **التحقق من التوقيع الثنائي (Magic Bytes):** فحص البايتات الأولى للملفات للتأكد من مطابقتها لنوع الملف الحقيقي ومنع التنكر البرمجي.
* **تطهير وتعمية أسماء المستندات:** تعمية وتجريد أسماء الملفات الظاهرة في القناة إلى `document_{uuid[:8]}{ext}` لمنع تسريب أسماء الطلاب من أسماء ملفاتهم، مع تشفير الاسم الأصلي في قاعدة البيانات وكشفه حصراً للمسؤول الأساسي في أمر `/whois`.
* **حماية من قنابل فك الضغط (Decompression Bombs):** رفض الصور التي تتجاوز أبعادها 8192 بكسل.
* **إعادة الرفع النظيفة والتنظيف الفوري:** رفع النسخة المطهرة إلى القناة وحذف الملف المؤقت فوراً في كتلة `finally`.

### 5. حماية المحتوى والوقاية من حقن الأكواد (Escaping & Content Protection)
* **ترميز HTML آمن:** تمرير جميع نصوص الطلاب والردود عبر `escape_user_content()` لمنع حقن وسوم HTML أو الروابط الموجهة.
* **منع إعادة التوجيه والنسخ:** نشر جميع الرسائل والصور والوسائط في القناة بتفعيل خاصية `protect_content=True`.
* **بوابة نشر موحدة (Publisher Gate):** حظر أي إرسال مباشر إلى القناة وحصره عبر `PublisherService` فقط.
* **نظام ردود مجهول متسلسل:** ربط الردود بالمنشورات الأصلية عبر إشارات رأسية مجهولة (`💬 رد على المنشور رقم #123`) دون استخدام معرفات ردود تيليجرام المكشوفة (`reply_to_message_id`) لضمان عدم تسريب تسلسلات الرسائل.
* **إعادة التحقق اللحظية (Late Revalidation):** إعادة فحص العضوية، الحظر، الكتم، وحالة النظام لحظة الإرسال الفعلي للرد.

## ⚙️ متطلبات التشغيل (Prerequisites)

* **Python:** 3.10 أو أحدث (تم الاختبار على Python 3.13).
* **قاعدة البيانات:** PostgreSQL 15+ (مع مجمع اتصالات asyncpg ودعم الترحيل عبر Alembic).
* **مكتبات النظام الأساسية:** `asyncpg`, `alembic`, `SQLAlchemy`, `Pillow`, `aiogram 3.x`, `cryptography`, `pydantic-settings`, `pymupdf`, `pypdf`, `pytesseract`.

## 🚀 التثبيت والتشغيل (Installation & Setup)

### 1. استنساخ المشروع وتثبيت الاعتماديات
```bash
# إنشاء بيئة افتراضية
python -m venv venv

# تفعيل البيئة (Windows)
.\venv\Scripts\activate
# تفعيل البيئة (Linux/macOS)
source venv/bin/activate

# تثبيت الحزم
pip install -r requirements.txt
```

### 2. إعداد قاعدة بيانات PostgreSQL وترحيل المخطط (Alembic)
```bash
# تطبيق أحدث ترحيلات قاعدة البيانات
alembic upgrade head
```

### 3. توليد مفاتيح الأمان وكلمة المرور المشفرة

#### أ) توليد مفتاح تشفير قاعدة البيانات (Fernet Encryption Key):
```bash
python utils/key_generator.py
```
*انسخ المفتاح الناتج وضعه في المتغير `ENCRYPTION_KEY` داخل `.env`.*

#### ب) توليد تجزئة كلمة مرور الإدارة (Scrypt Password Hash):
```bash
python utils/hash_password.py "كلمة_مرور_الإدارة_القوية_هنا"
```
*انسخ التجزئة الناتجة (تبدأ بـ `scrypt$...`) وضعها في المتغير `ADMIN_PASSWORD_HASH` داخل `.env`.*

### 4. إعداد ملف البيئة (`.env`)
قم بنسخ ملف `.env.example` إلى `.env` واملأ المتغيرات:

## 📖 دليل الأوامر الإدارية (Admin Commands Guide)

| الأمر | الصلاحية | الوصف |
| :--- | :--- | :--- |
| `/admin` | جميع الإداريين | فتح لوحة التحكم التفاعلية وطلب كلمة المرور (2FA) |
| `/whois <رقم_الطالب_أو_المنشور>` | **Primary Admin فقط** | كشف هوية الطالب الحقيقية المشفرة وصاحب المنشور واسم الملف الأصلي |
| `/set_admin_password <id> <pass>` | **Primary Admin فقط** | تعيين كلمة مرور فردية خاصة بمشرف محدد وحفظها مشفرة في SQLite |
| `/dm <رقم_الطالب> <الرسالة>` | **Primary Admin فقط** | إرسال رسالة خاصة رسمية مجهولة للطالب عبر البوت |
| `/wipe_student <رقم_الطالب>` | **Primary Admin فقط** | تطهير وحذف كافة بيانات الطالب الشخصية (GDPR Wipe) |
| `/broadcast <الرسالة>` | **Primary Admin فقط** | إرسال إذاعة عامة وتنبيه لجميع الطلاب المسجلين |
| `/ban <رقم_الطالب> [السبب]` | المشرفون والمسؤول | حظر الطالب نهائياً من المشاركة والنشر |
| `/unban <رقم_الطالب>` | المشرفون والمسؤول | إلغاء حظر الطالب وتمكينه من المشاركة مجدداً |
| `/mute <رقم_الطالب> <الدقائق>` | المشرفون والمسؤول | كتم الطالب مؤقتاً لعدد محدد من الدقائق |
| `/unmute <رقم_الطالب>` | المشرفون والمسؤول | إلغاء الكتم المؤقت عن الطالب فوراً |
| `/del <رقم_رسالة_القناة>` | المشرفون والمسؤول | حذف منشور أو رد محدد من القناة وقاعدة البيانات |
